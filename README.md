# Faceless Reels Factory

Turn an idea into a finished **1080×1920 vertical video** (Instagram Reels, TikTok, YouTube Shorts) on your own Mac.
Characters act the story out, captions pop in word by word in time with the voice, and you get a cover image, a
caption draft and a fact-check report with every video.

- **Animated story scenes, not text slides.** Bean people and little bots with moods, poses, speech bubbles and
  emotes act in sets (stage, island, office, lab, city, cyber, night, room), with a moving camera, transitions,
  counters, swarms and automatic sound effects.
- **Runs locally.** Every frame is an SVG built in Python, rasterised by `rsvg-convert` and encoded by FFmpeg.
  There's no cloud renderer and no stock footage, and the graphics, sound effects and fallback music are all
  generated by the code.
- **Your voice.** Record the script yourself, or let an optional ElevenLabs voice clone read it. whisper.cpp
  times every word, so the captions and the animation follow the real voice.
- **Writing with Claude Code.** The `/reel` command reads the source, fact-checks it, writes the script and
  storyboard, checks it and shows you preview stills before anything costs money.
- **You stay in control.** Nothing is posted automatically. Every video is validated (resolution, codec,
  loudness, caption safe zones, blank frames), and any claims marked uncertain are listed for you to check.

```
idea ─► /reel (Claude Code) ─► check ─► preview --dry ─► your OK ─► voice ─► render ─► review ─► you post it
```

## Try it in five minutes (no accounts, no keys)

Needs macOS, [Homebrew](https://brew.sh) and Python 3.11+.

```bash
brew install ffmpeg librsvg whisper-cpp uv
```

```bash
git clone https://github.com/MuhammadMurtuzaHussain/faceless-reels-factory.git && cd faceless-reels-factory
```

```bash
uv venv .venv && uv pip install --python .venv/bin/python -e ".[dev]"
```

```bash
.venv/bin/python -m reelfactory doctor
```

Render preview stills of the bundled example storyboard. This needs no voice and no API keys:

```bash
cp docs/examples/EXAMPLE-001.json data/scripts/ && .venv/bin/python -m reelfactory check EXAMPLE-001 && .venv/bin/python -m reelfactory preview EXAMPLE-001 --dry
```

Open `output/drafts/EXAMPLE-001.preview.jpg`. To make the full video, record the script (QuickTime → New Audio
Recording), save it as `inbox/voiceovers/EXAMPLE-001.m4a`, and render:

```bash
.venv/bin/python -m reelfactory render EXAMPLE-001
```

For word-accurate captions, download the whisper model once (about 148 MB):

```bash
curl -L -o models/ggml-base.en.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin
```

## Make it yours

Everything about your account lives in [config/style.json](config/style.json):

| Key | What it is |
|---|---|
| `handle`, `niche` | Your @handle and a few words about your channel; used in the on-screen tag, Claude briefs and caption drafts |
| `profile` | Username, display name, bio lines and `avatar` (a photo path such as `assets/brand/avatar.jpg`, or `null` for a monogram) for the Follow end card |
| `cta` | The closing call to action: the spoken line, the end-card headline, or `"enabled": false` |
| `colors`, `fonts`, `themes.story` | The look. The light editorial theme is the default for `card` scenes; `story` scenes use the dark story theme |
| `voice` | ElevenLabs model and voice settings, plus `monthly_characters` for the credit meter |
| `audio.music` | Background music: `generated` (original, free), `elevenlabs`, `file` (your own licensed track) or `off` |

The news feeds and the ranking weights are in [config/feeds.json](config/feeds.json). Swap in feeds for your own niche.

## Making videos

The fast path is `/reel` in [Claude Code](https://claude.com/claude-code), opened in this folder. It works with a
shortlist number, an idea note, or plain text:

```
/reel 2
/reel my-idea.md
/reel why do phone batteries hate the cold
```

It follows [.claude/skills/reel/SKILL.md](.claude/skills/reel/SKILL.md): research → script → storyboard → `check` →
`preview --dry` → asks you → `ready` → voice + render. The same steps work by hand from the command line, and with
any chat assistant, because each idea comes with a brief you can paste. See the [guide](GUIDE.md).

Ideas come from two places:
- **RSS shortlist:** `reelfactory daily` fetches your feeds, ranks the stories and explains each score.
- **Your notes:** drop `.md` files in `inbox/ideas/` (the first `# heading` is the title and any links are the sources).

## Optional extras

- **ElevenLabs voice clone** (paid): set `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID` in `.env`, and finished
  storyboards are voiced automatically. Voicing is refused when a storyboard fails `check`, so you don't pay for
  broken takes, and a credit meter tracks your monthly characters.
- **Telegram + n8n control panel** (free): a bot that sends you the daily shortlist and each finished video, cover
  and caption, and takes `/pick`, `/approve` and `/published` commands.
- **Local dashboard:** http://127.0.0.1:8765 for the same review loop in the browser.
- **Background mode:** `sh scripts/install-launchd.sh` runs the API and n8n from login.

Everything listens on 127.0.0.1 only, and secrets stay in the git-ignored `.env`. The [guide](GUIDE.md) covers setup,
the storyboard format and how it all works. The full scene vocabulary is in [docs/story-scenes.md](docs/story-scenes.md).
